# 🧶 Knit E-Commerce

A modern and responsive e-commerce website built to provide a seamless online shopping experience for knitted and fashion products. The project focuses on clean UI, smooth navigation, and an attractive user experience.

## 🚀 Features

- Responsive design for all devices
- Modern and user-friendly interface
- Product listing with attractive cards
- Category-based product browsing
- Product details page
- Shopping cart functionality
- Fast and optimized performance
- Smooth animations and transitions

## 🛠️ Tech Stack

- React.js
- Vite
- HTML5
- CSS3
- JavaScript (ES6+)

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Vibhor2714/-E-commerce.git
```

Go to the project folder:

```bash
cd -E-commerce
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## 🌐 Deployment

The project is configured for deployment on **Vercel**.
